# العناصر الأربعة والأثير الكوني (The Four Elements & Quintessence)

بنية المادة الكونية في الفلسفة اليونانية والإسلامية والخيميائية القديمة تتألف من أربع طبائع وعنصر خامس مهيمن:

---

## 1. المصفوفة الثنائية للطبائع الأربعة
تتولد العناصر من تزاوج أربع كيفيات أساسية (الحرارة، البرودة، الرطوبة، اليبوسة):

```
             [ حار ] (Hot)
           /               \
[ نار - Fire ]            [ هواء - Air ]
   (حار + يابس)              (حار + رطب)
       |                         |
       |     [ الأثير / الهيولى ]    |
       |      (Quintessence)     |
       |                         |
[ تراب - Earth ]          [ ماء - Water ]
   (بارد + يابس)             (بارد + رطب)
           \               /
             [ بارد ] (Cold)
```

## 2. العنصر الخامس: الأثير (Quintessence / Ether)
- **الأثير (الهيولى الأولى):** هو المادة اللطيفة النقية التي تملأ الفضاء العلوي، وهي الحامل للاهتزازات النورية وحركات الأفلاك السماوية.
- لا يتغير ولا يفسد، ومنه تتكثف العناصر الأربعة في العالم السفلي.

## 3. ارتباط العناصر بدورات القِرانات الفلكية
كما وثق [[Great_Conjunctions_Abu_Mashar]]، فإن التاريخ البشري والحضاري ينتقل كل 240 سنة من مثلث عنصر إلى مثلث عنصر آخر، متبعاً الترتيب الدائري الكوني:
$$\text{النار} \longrightarrow \text{التراب} \longrightarrow \text{الهواء} \longrightarrow \text{الماء}$$
