# منظومة الأفلاك المتجسدة: الميلوثيسيا (Melothesia)

**الميلوثيسيا (Melothesia / Iatromathematics):** هي العقيدة الفلكية-الطبية القديمة القائلة بأن أعضاء الجسد البشري خاضعة مباشرة لتأثير الأبراج السماوية والكواكب السبعة، بحيث يمثل الإنسان الصغير (Microcosm) صورة متطابقة من الكون الكبير (Macrocosm).

---

## 1. التوزيع التشريحي للبروج على الجسد البشري
يبدأ التوزيع من أعلى نقطة في الجسد (الرأس) مع أول الأبراج (الحمل)، وينحدر تدريجياً حتى القدمين مع آخر الأبراج (الحوت):

| البرج | العضو المقابل في الجسد | الدلالة الفسيولوجية والطبية |
| :--- | :--- | :--- |
| **الحمل (Aries)** | الرأس والدماغ والعينان | التفكير، الاندفاع العصبي، الصداع، الجيوب الأنفية |
| **الثور (Taurus)** | العنق والحنجرة والغدة الدرقية | النطق، البلع، الأوتار الصوتية، الرقبة |
| **الجوزاء (Gemini)** | الكتفان والذراعان والرئتان والجهاز العصبي | التنفس، الحركة الثنائية، التواصل الحركي |
| **السرطان (Cancer)** | الصدر والثديان والمعدة | التغذية، الهضم العاطفي، الحماية |
| **الأسد (Leo)** | القلب والعمود الفقري والشرايين | مضخة الحياة، مركز الطاقة الحيوية والسيادة |
| **العذراء (Virgo)** | الأمعاء والبطن والجهاز الهضمي السفلي | التصفية، التمييز الغذائي، امتصاص العناصر |
| **الميزان (Libra)** | الكليتان وأسفل الظهر والأرداف | التوازن الأسموزي والسوائل في الجسم |
| **العقرب (Scorpio)** | الأعضاء التناسلية وجهاز الإخراج | التناسل، الموت الخلوي، التجدد الكيميائي |
| **القوس (Sagittarius)** | الفخذان والوركان والعصب الوركي | الحركة الكبرى، السير، الركض، الاستكشاف |
| **الجدي (Capricorn)** | الركبتان والعظام والمفاصل والجلد | الهيكل الصلب، الحدود الجسدية، التحمل |
| **الدلو (Aquarius)** | الساقان والكاحلان والدورة الدموية | التوصيل الكهربائي العصبي، التداول الشبكي |
| **الحوت (Pisces)** | القدمان وجهاز المناعة اللمفاوي | الاتصال بالأرض، الحساسية القصوى، الذوبان |

## 2. التوثيق التاريخي عبر الحضارات
1. **في روما القديمة:** وثقها الفلكي الروماني [[Marcus_Manilius_Astronomica]] في القرن الأول الميلادي في كتابه الشهير *Astronomica*.
2. **في الهند القديمة:** تكررت حرفياً في النص السنسكريتي الشهير [[Yavanajataka_Sphujidhvaja]] (الفلك اليوناني-الهندي)، مجسدة على الإله الكوني **كالا براجاباتي (Kala Purusha / Prajapati)**.
3. **في الطب العربي والوسيط:** اعتمد عليها الأطباء والفلاسفة (مثل ابن سينا والرازي وأبو معشر) في تحديد أوقات الحجامة والفصد وتناول الأدوية المسهلة تبعاً لحركة القمر في البروج وتجنب المساس بالعضو عندما يكون القمر في برجه.
